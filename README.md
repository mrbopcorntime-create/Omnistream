# OmniStream

One Android app for streaming your gaming PC (Sunshine) and Xbox, with LAN discovery and Wake-on-LAN.

- **PC streaming** runs in-app on the open-source [Moonlight](https://github.com/moonlight-stream/moonlight-android) engine (GPLv3), merged in at build time by `integrate.py`.
- **Xbox remote play** runs in-app through Microsoft's web player.
- **Dashboard, Scan, Wake & Connect** live in `omnistream/src`.

## Get the APK
Every push builds automatically (Actions tab). The APK is attached to the newest entry under **Releases**.

Licensed GPLv3, like the Moonlight engine it includes.
